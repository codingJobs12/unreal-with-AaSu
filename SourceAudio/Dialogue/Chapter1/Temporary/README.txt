Format: 48 kHz, 16-bit PCM, mono WAV.
Regeneration: run GenerateTemporaryDialogue.ps1 from PowerShell.
Dialogue source: ProjectDocs/CHAPTER 1 — Voice Actor Lines.pdf and
ProjectDocs/Mansions Quests_ Chapter 1.pdf. The generated lines preserve client-provided wording.

Replacement workflow:
1. Keep the existing VO_TEMP asset names.
2. Replace each source WAV with the approved final performance.
3. Reimport the matching Unreal SoundWave.
4. Verify subtitle text and timing against the approved recording.
